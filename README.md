# Thai Practice

A personal Thai review app: vocabulary, grammar patterns, real-situation prompts, listening, and endless random time/number drills. Everything is in romanization (speaking first). It works offline once opened, and progress is saved on the device.

**Open it:** https://spoonkiller03-cmd.github.io/thai-language-practice/
On iPhone, open it in Safari, then Share › Add to Home Screen. On Android, open it in Chrome, then ⋮ › Add to Home screen.

Lesson content lives in `data/lessons/`. See `CLAUDE.md` for how updates are made.
